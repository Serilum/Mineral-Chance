<h2><br><img src="https://cdn.serilum.com/description/nameplate/about-the-mod.svg" alt="About the mod" width="838" height="64"></h2>
<p><span style="font-size:18px">Mineral Chance is a mod created to make mining a little bit more exciting. It adds a chance to find a random mineral after mining a stone-type block. In the overworld these stone blocks are <strong><em>stone, andesite, diorite, granite, tuff and deepslate</em></strong>. In the nether it's <em><strong>netherrack, basalt and blackstone</strong></em>. More blocks can be added in the config.<br><br>By default there is a 1/50 chance to find a mineral. The overworld minerals consist of <em><strong>diamonds, iron nuggets, gold nuggets, copper nuggets, lapis lazuli, redstone and emeralds</strong></em>. The nether minerals consist of <em><strong>quartz, golden nuggets and netherite scraps(1.16+)</strong></em>. Mining with Silk Touch will disable mineral drops.<br><br>Each mineral has its own weight, so diamonds, emeralds and netherite scraps are a lot rarer than nuggets. Which minerals can drop and how often can be changed in the config, modded items included. Fortune increases the chance to find one, and modded mining tools such as hammers work as well. The message when finding a random mineral can be changed and turned off in the config.</span></p>

<p><a href="https://serilum.com/configuration-guide" target="_blank" rel="nofollow"><img src="https://cdn.serilum.com/description/badges/configuration-guide.svg" alt="Configuration guide" width="220" height="49"></a></p>
<p>&nbsp;&nbsp;&nbsp;<span style="font-size:18px">All available config options:</span></p>
<div class="spoiler" style="margin-left:10px;padding-left:10px">
<p><br><span style="font-size:14px"><strong>extraMineralChanceOnOverworldStoneBreak</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default 0.02, min 0, max 1.0</span><br><span style="font-size:13px">The chance a mineral is dropped when an overworld stone block is broken. By default 1/50.</span><br><br><span style="font-size:14px"><strong>extraMineralChanceOnNetherStoneBreak</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default 0.01, min 0, max 1.0</span><br><span style="font-size:13px">The chance a mineral is dropped when a nether stone block is broken. By default 1/100.</span><br><br><span style="font-size:14px"><strong>enableOverworldMinerals</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default true</span><br><span style="font-size:13px">If enabled, mining overworld stone blocks has a chance to drop an overworld mineral.</span><br><br><span style="font-size:14px"><strong>enableNetherMinerals</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default true</span><br><span style="font-size:13px">If enabled, mining nether stone blocks has a chance to drop a nether mineral.</span><br><br><span style="font-size:14px"><strong>overworldMineralDrops</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default "minecraft:iron_nugget=10,minecraft:gold_nugget=8,minecraft:copper_nugget=8,minecraft:redstone=6,minecraft:lapis_lazuli=6,minecraft:emerald=2,minecraft:diamond=1"</span><br><span style="font-size:13px">The minerals overworld stone can drop. A higher weight drops more often. Item tags work too, starting with a '#'.</span><br><br><span style="font-size:14px"><strong>netherMineralDrops</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default "minecraft:quartz=10,minecraft:gold_nugget=10,minecraft:netherite_scrap=1"</span><br><span style="font-size:13px">The minerals nether stone can drop. A higher weight drops more often. Item tags work too, starting with a '#'.</span><br><br><span style="font-size:14px"><strong>extraOverworldMineralBlocks</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default ""</span><br><span style="font-size:13px">Extra blocks that can drop overworld minerals. Block tags work too, starting with a '#'.</span><br><br><span style="font-size:14px"><strong>extraNetherMineralBlocks</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default ""</span><br><span style="font-size:13px">Extra blocks that can drop nether minerals. Block tags work too, starting with a '#'.</span><br><br><span style="font-size:14px"><strong>enableMineralsInOtherDimensions</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default true</span><br><span style="font-size:13px">If enabled, stone blocks in other dimensions, such as the end, can drop minerals too.</span><br><br><span style="font-size:14px"><strong>dimensionsWithoutMinerals</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default ""</span><br><span style="font-size:13px">Dimensions in which no minerals are dropped.</span><br><br><span style="font-size:14px"><strong>fortuneChanceMultiplierPerLevel</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default 0.5, min 0, max 10.0</span><br><span style="font-size:13px">How much each Fortune level increases the mineral chance. 0.5 means +50% per level.</span><br><br><span style="font-size:14px"><strong>explosionsCanDropMinerals</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default false</span><br><span style="font-size:13px">If enabled, stone blocks destroyed by explosions can drop minerals too.</span><br><br><span style="font-size:14px"><strong>extraMiningTools</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default ""</span><br><span style="font-size:13px">Extra items that count as a pickaxe, such as mining lasers. Item tags work too, starting with a '#'.</span><br><br><span style="font-size:14px"><strong>disableMineralDropsWithSilkTouch</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default true</span><br><span style="font-size:13px">If enabled, minerals won't drop from stone mined with the silk touch enchantment.</span><br><br></p>
<p><span style="font-size:14px"><strong>sendMessageOnMineralFind</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default true</span><br><span style="font-size:13px">If enabled, sends a message when a mineral is found to the player who broke the stone block.</span><br><br><span style="font-size:14px"><strong>foundMineralMessage</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default "You've found a mineral hidden in the block!"</span><br><span style="font-size:13px">The message sent to the player who found a hidden mineral when 'sendMessageOnMineralFind' is enabled.</span><br><br><span style="font-size:14px"><strong>ignoreFakePlayers</strong></span><span style="font-size:12px;color:#8a8d91">&nbsp;&nbsp;default true</span><br><span style="font-size:13px">If enabled, minerals won't be dropped if the player is a fake. For example when a mod breaks a block as a simulated player.</span></p>
